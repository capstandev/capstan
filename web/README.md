# web

The Capstan site and dashboard: Vite, React and TypeScript, plain CSS, system fonts (nothing is loaded from a third
party), no analytics or trackers.

Pages: `/` (landing), `/docs` (the generated OpenAPI file and the MCP tool table), `/pricing`, `/status`, `/verify`
(receipt verification in the browser), `/legal` (risk disclaimer, restricted regions, DB-IP attribution) and `/app`
(the dashboard).

The app imports the SDK and the receipts library from `../packages/*/src` (see `src/lib/capstan.ts`), so install the
repo root first.

```bash
bun install            # at the repo root
cd web && bun install
bun run dev            # http://127.0.0.1:22273, API at http://127.0.0.1:22210/v1
bun run build          # sync the OpenAPI copy, typecheck, vite build, then check dist/
bun run test           # happy-dom tests, plus headless Chromium checks when Chromium is installed
bun run check:copy     # banned words and the site copy rules over every rendered page
bun run test:e2e       # browser pass on the local stack; screenshots go to the private docs repo
```

## Dashboard (`/app`)

A thin UI over the SDK (`packages/sdk`): it never builds or edits a payload. Connect (EIP-6963 injected wallets),
onboarding per venue (preflight, the SDK-checked step list before any wallet prompt, the builder step in plain words,
`fee_free_unavailable` when declined), quote table, order ticket (the SDK's check and digest, then sign and send),
risk cards per venue under the fixed banner, receipts with links to `/verify`, policy editor and kill switch, and the
spread planner (ack checkbox and signed ack text before Execute). Trade-only keys live in the SDK's `browserKeyStore`
(non-extractable AES-GCM in IndexedDB); the page shows the agent address and expiry only.

## Configuration (build time)

| Variable | Default | Meaning |
| --- | --- | --- |
| `VITE_PROFILE` | `live` | `fork` points at the local stack and an anvil fork, shows "Local test network" and refuses writes from chain 4663 |
| `VITE_API_BASE` | `http://127.0.0.1:22210/v1` in dev, `https://api.capstan.finance/v1` in a build | Capstan API base |
| `VITE_NETWORK` | `mainnet` (`testnet` on the fork profile) | SDK pins and token chain |
| `VITE_RPC_URL` | Robinhood Chain public RPC (`http://127.0.0.1:22245` on the fork profile) | Anchor reads on `/verify` |
| `VITE_REOWN_PROJECT_ID` | unset | WalletConnect through Reown; unset means injected (EIP-6963) wallets only |

Fork profile only: `VITE_PINS`, `VITE_VENUE_HOSTS`, `VITE_RECEIPT_SIGNERS`, `VITE_ANCHOR` and `VITE_ANCHOR_CHAIN_ID`
override the SDK pins for a local stack.

## Rules the tests hold

- The risk disclaimer is on `/`, `/docs`, `/pricing`, the dashboard and inside every quote widget.
- The token-address box appears only when `public/contracts.json` (generated by `ops/ci/gen-deployments.ts`) has a
  CPST address for the build's chain.
- Every landing claim has a row in `CLAIMS.md` with how to check it today; claims that are not live stay off the page
  (`src/live.ts`).
- `/docs` shows exactly `apps/api/openapi.json` (copied by `scripts/sync-openapi.ts`).
- No source maps, server paths or `.env` values in `dist/` (`scripts/check-dist.ts`).
- No animations, status badges, sparkle icons or numbered feature cards.
