# Supplied component references

These five TSX files are preserved from the project owner's supplied prompts. The live Capstan pages are a static HTML/CSS/JavaScript frontend; they use adapted implementations in `capstan-attached-a.js` and `capstan-attached-a.css`, so no React, Tailwind, TypeScript or shadcn installation is needed to run them. The supplied donation link and demo claims are not used in the live site.

To use the TSX originals in a separate React application, first set up React and TypeScript and follow the Tailwind installation instructions appropriate to its build tool. Then run `npx shadcn@latest init` from that application. Configure the `@/` alias and the component and style paths prompted by shadcn. A `/components/ui` folder is useful when matching the originals' `@/components/ui/...` imports, but it is not mandatory if the imports and shadcn configuration are changed to your project's actual component path. Install each component's stated dependencies and provide its referenced hooks and utility functions before importing it. Do not include the original external donation URL or placeholder statistics in the product without an explicit product decision.
