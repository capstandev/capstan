# Deployment files

One file per chain, `<chainId>.json`, is the only source of truth for our own contract addresses. Every other copy
(`packages/schema/src/generated/deployments.ts` and the tables in `README.md` and `SECURITY.md` between the
`<!-- deployments:start -->` and `<!-- deployments:end -->` markers) is generated by `bun ops/ci/gen-deployments.ts`,
and `bun ops/ci/check-deployments.ts` (CI and pre-commit) fails when a copy differs or a file is malformed. Deploy
scripts write these files; nobody edits the copies by hand.

Schema:

```json
{
  "chainId": 46630,
  "contracts": {
    "CapstanReceiptAnchor": { "address": "0x...", "txHash": "0x...", "block": 123, "poster": "0x..." },
    "CPSTLock": { "address": "0x...", "txHash": "0x...", "block": 124 },
    "CPST": { "address": "0x...", "symbol": "CPST", "decimals": 18, "supply": "1000000000000000000000000000" }
  },
  "deployer": "0x...",
  "sourcify": { "verified": true, "url": "https://..." },
  "updatedAt": "2026-11-05T00:00:00Z"
}
```

Rules: the file name equals `chainId`; addresses are 20-byte hex; `txHash` is a 32-byte hash; amounts are decimal
strings. With no file present every copy is empty and the check passes.
